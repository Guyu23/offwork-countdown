## 文案节奏

1. 封面只保留一句主标题和一句副标题。
2. 第二张解释“它只做一件事”，不展开功能清单。
3. 第三张用四张真实截图说话，文字只做标注。
4. 第四张把情绪推到“今天辛苦了”，不解释技术。
5. 第五张给出去处，二维码 + GitHub 名称，不写长段落。
