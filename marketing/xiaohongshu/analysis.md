# 内容分析

## 基本信息

- 主题：一个很小的 Windows 下班倒计时桌面挂件
- 类型：独立产品分享 / 桌面美化 / 打工人情绪价值
- 受众：长时间坐在电脑前、喜欢克制审美和小工具的人；Windows 用户
- 核心卖点：简单、漂亮、安静；只做下班倒计时这一件事
- 情绪钩子：离下班还有一点时间；到点了，今天辛苦了

## 视觉机会

1. 大号数字本身就是主视觉，截图比插画更有说服力。
2. 四种背景提供天然的系列感，可以做一张四宫格。
3. “今天辛苦了”是情绪落点，适合单独一张。
4. 贴边收起和胶囊模式是动作感，适合用前后对比或一张单独图。
5. 二维码放在最后一张，形成完整的浏览闭环。

## 推荐

- 策略：C 视觉优先
- 风格：minimal
- 布局：sparse 与 balanced 交替
- 配色：深青墨蓝底、奶油白字、落日橘点缀
- 图片：5 张，1080 × 1440
- 素材：真实产品截图；不使用 AI 生成的界面或文字，避免与产品不一致
- 渲染：以真实截图和 HTML 排版输出 PNG，保证中文标题和 UI 清晰准确
